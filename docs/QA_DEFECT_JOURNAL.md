Дополнение владельца в этом же цикле: исключить обед 13:00–14:00. Общий серверный расчёт вычитает только пересечение отметок с каждым обеденным интервалом по BUSINESS_UTC_OFFSET (по умолчанию UTC+5, как границы рабочего дня). 09:00–18:00 = 8 часов; 13:30–14:30 = 0,5 часа; ночная смена без пересечения не сокращается. Итог вычисляется из исходных отметок при чтении, поэтому прежние записи получают то же правило без массовой правки истории и без двойного вычитания из сохранённого итога. Новое закрытие личного/полевого дня сохраняет уже чистые часы. Табель, личная история и файлы используют этот результат. Таймер незавершённого личного дня явно подписан как время с начала, включая обед.
